# ParkPark 출시 가이드 (사용자용, 2026-10-13)

코드 쪽에서 할 수 있는 출시 준비는 끝났습니다. 이 문서는 **사용자만 할 수 있는 일**을 순서대로 적은 것입니다.
각 단계가 끝나면 "다 했어"라고만 알려 주시면 저는 다음 코드 작업(템플릿 제작, 수정, 문서)을 바로 이어서 합니다.

## 0. 지금 상태

- 모든 구역 12개, 놀이기구 66개, 개인 공원(사람마다 자기 공원), 친구 방문, 순위판, 음악, 영어 화면, 분석 지표가 들어 있습니다.
- 첫 접속 흐름(입구 청소 → 회전목마 수리 → 개장 → 손님 입장)을 처음 상태에서 다시 확인했고 오류가 없었습니다.
- 18분 연속 가동에서 서버 인스턴스와 프레임이 안정적이었습니다.
- 게시된 장소에서만 동작하는 것(텔레포트, 친구 방문, 초대, 순위판, 분석)은 아직 확인하지 못했습니다. 그래서 정식 공개 전에 **베타 게시와 친구 시험(3단계)** 이 꼭 필요합니다.

## 1. 지금 바로 (30분)

1. **Rojo 다시 시작**: 로딩 화면을 위해 `default.project.json`에 `ReplicatedFirst`가 추가됐습니다.
   프로젝트 루트에서 `rojo serve default.project.json`을 다시 켜고 Studio의 Rojo 플러그인에서 **Connect**를 누르세요.
   (Studio 장소에는 로딩 스크립트가 이미 들어가 있어서, 다시 연결하지 않아도 게시본에는 포함됩니다.)
2. **모델 5개 가져오기**(3D Importer, 이전과 같은 방식): `assets/models/parkpark/`의
   `ParkParkLandmarkTicket`, `ParkParkLandmarkSponsor`, `ParkParkLandmarkLounge`, `ParkParkBalloonPad`, `ParkParkBalloonBalloon`.
   가져온 뒤 알려 주시면 ID를 기록하고 템플릿을 만듭니다. (안 가져와도 도형으로 동작합니다.)
3. **폰 확인**(직접 해 보실 항목):
   - 첫 화면: 로딩 화면이 보였다가 사라지는지, 안내 카드가 보이는지.
   - 버튼 6개(이동, 꾸미기, 미션, 도감, 친구 공원, 음악)가 겹치지 않고 눌리는지, 패널이 화면을 벗어나지 않는지.
   - 길게 누르기(수리 콘솔, 쓰레기, 줍기)가 터치로 되는지, 관리 패널의 버튼이 손가락으로 눌리는지.
   - 알림이 아래 가운데에 보이고 조이스틱·점프 버튼을 가리지 않는지, 모노레일 탑승이 되는지.
   - 프레임이 끊기지 않는지(끊기면 알려 주세요: 장식 개수·손님 수를 줄입니다).

## 2. 베타 게시 (별도 경험으로)

1. Studio에서 **File → Publish to Roblox As...** 로 **새 경험**을 만드세요(이름 예: `ParkPark Beta`). 기존 경험을 덮어쓰지 않고,
   저장 데이터(DataStore)도 경험별로 분리되어 있어 안전합니다.
2. 새 경험의 **Game Settings**에서:
   - **Security**: *Enable Studio Access to API Services* 켜기(저장과 순위판에 필요), *Allow HTTP Requests*는 끄기.
   - **Places → Max Players**: **12** 권장(개인 공원에 친구가 놀러 오는 구조라 60은 필요 없습니다).
   - **Devices**: 컴퓨터, 휴대폰, 태블릿만 켜고 **콘솔은 끄기**(게임패드 조작을 확인하지 못했습니다).
   - **Privacy**: 베타 동안 **Private**(친구만 초대) 또는 Friends.
3. **Creator Hub에서 데이터 저장 허용**이 이미 켜져 있는지 확인(Studio 보안 설정과 별개로 웹에서도 켜야 합니다).

## 3. 친구 시험 (2~3명, 약 30분)

세 명이 각각 한 번씩 아래를 합니다. 안 되는 항목을 알려 주세요.

| 단계 | 확인 | 기대 결과 |
|---|---|---|
| 1 | 각자 베타에 접속 | 몇 초 뒤 "내 공원"으로 이동(화면이 잠깐 로딩), 공원 이름 표시 없음 |
| 2 | A가 입구 청소 → 회전목마 수리 → 개장 | 손님이 오고 코인이 오름, 저장됨 |
| 3 | A가 "친구 공원" → 초대 | B에게 초대 알림, B가 수락 |
| 4 | B가 들어옴 | B가 A의 공원으로 이동, 화면 위에 "A의 공원 방문 중" |
| 5 | B가 수리·해금 시도 | "방문 중이에요" 알림으로 거부, B도 손님처럼 코인을 얻고(절반) 줍기·부스·낚시 가능 |
| 6 | B가 "내 공원으로" | B의 공원으로 돌아감, B의 진행은 그대로 |
| 7 | C가 "친구 공원" 목록에서 A를 방문 | 방문됨 |
| 8 | A가 나가고 다시 들어옴 | 진행이 이어짐(저장), A의 공원으로 복귀 |
| 9 | 광장 순위판, 음악 | 순위판에 이름과 숫자가 나타남(5분 뒤), 음악 재생과 "음악" 끄기 |
| 10 | 영어 시험: 휴대폰 언어를 영어로 | 화면이 영어로 표시 |

실패하면 서버 로그가 필요합니다: Creator Hub → 경험 → **Analytics/Server logs**(또는 Studio의 Output) 캡처를 보내 주세요.

## 4. 정식 공개 직전

- [ ] 베타에서 3단계 표가 모두 통과
- [ ] 아이콘 1장 + 썸네일 3~5장(아래 제안), 이름, 설명(아래 문구)
- [ ] **Experience Guidelines(연령 설문)**: 아래 답안을 참고해 직접 응답(계정 책임이라 대신 할 수 없습니다)
- [ ] 정식 경험(기존 `ParkPark`)에 같은 장소를 **Publish**하고 *Max Players 12*, *Devices 콘솔 끄기*, *API Services 켜기*를 동일하게 설정
- [ ] (선택) 후원자 패스를 만들면 `GameConfig.Monetization.PassId`에 ID를 붙여 넣기(알려 주세요)
- [ ] 공개 범위를 **Public**으로

### 연령 설문 참고 답안(실제 내용 기준)

- 폭력/무기: 없음(사격장 부스는 장난감 사격, 피해 표현 없음).
- 공포: 약함("유령의 집", "유령선"은 그림책풍 장식, 갑작스러운 공포 연출 없음).
- 도박/현금화: 로벅스로 확률형 아이템을 팔지 않음. 부스의 보상은 게임 코인뿐이며 코인은 로벅스로 살 수 없음.
- 사용자 제작 콘텐츠/채팅: Roblox 기본 채팅만 사용, 자체 입력창 없음.
- 현금 결제: 현재 없음(후원자 패스 만들기 전까지).

## 5. 스토어 문구 제안

**이름 후보**: `ParkPark: 폐장한 놀이공원 되살리기` / 영어 `ParkPark: Revive the Theme Park`

**짧은 설명(한국어)**: 문 닫은 놀이공원을 되살려 보세요. 쓰레기를 치우고, 놀이기구를 고치고, 개장하고, 바다·우주·사탕 나라까지 공원을 넓혀 가요. 친구를 내 공원에 초대하세요.

**상세 설명(한국어)**:
쓰레기를 치우고 코인을 모아 회전목마부터 고쳐 보세요. 개장하면 손님이 찾아오고 놀이기구가 코인을 벌어 줍니다.
- 12개 테마 구역: 물, 어린이, 모험, 겨울, 우주, 해적섬, 사탕, 정글, 사막, 구름, 해저, 로봇 도시
- 놀이기구 60여 개와 가게, 모노레일, 열기구
- 줍기·낚시·배달·미니게임으로 직접 코인 벌기, 매일 미션과 주간 목표, 도감과 업적
- 내 공원은 나만의 공간. 친구를 초대하거나 친구 공원에 놀러 갈 수 있어요
- 비와 무지개, 밤, 계절 행사, 정전 같은 사건이 공원을 바꿔요

**Short description (English)**: Bring a closed theme park back to life. Clean up, repair rides, open the gates and grow your park across twelve themed zones. Invite friends to visit.

**Genre**: Tycoon / Simulation. **태그**: tycoon, theme park, building, friends, cozy.

**썸네일 구성(5장)**: (1) 개장 전 폐허 입구와 개장 후 색이 살아난 입구 나란히 (2) 회전목마와 손님 (3) 대관람차와 노을 (4) 해저/로봇 도시 풍경 (5) 친구 3명이 함께 있는 광장. Studio의 **Thumbnail 도구**나 화면 캡처로 1920×1080에 가깝게 찍으세요.

## 6. 출시 후 첫 주

- **매일**: Creator Hub → Analytics에서 접속 유지율, 온보딩 퍼널(입구 청소, 개장, 세 번째 놀이기구, 첫 구역), 코인 경제를 봅니다.
  퍼널에서 급격히 떨어지는 단계가 있으면 알려 주세요(튜토리얼이나 숫자를 조정).
- **오류**: Creator Hub의 서버 로그에서 `[ParkPark]` 경고를 확인합니다. 저장 관련 경고가 있으면 바로 알려 주세요.
- **수정 배포**: 수정 → `verify.ps1` 통과 → Studio에서 게시. 문제가 생기면 Creator Hub의 **Version history**로 이전 버전을 복원할 수 있습니다.
- **저장 데이터 주의**: 형식이 바뀌면 `Version`을 올려야 합니다(더 새 형식의 저장은 옛 버전이 건드리지 않도록 막아 두었습니다).
