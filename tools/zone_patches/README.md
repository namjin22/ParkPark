# 구역 추가 패치 스크립트 (참고용)

새 구역을 추가할 때 사용한 일회성 패치 스크립트입니다. 각 스크립트는 그 시점의 `GameConfig`,
`ParkLayout`, `ExtraRides`, `DecorService`, `Bootstrap`, 메시 생성기, 템플릿 빌더의 문자열 앵커에
맞춰져 있어 **이미 적용된 상태에서는 다시 실행되지 않습니다.** 다음 구역(예: 14번째)은
`zones_tech.py`를 복사해 `ZONE` 사양(키, 이름, 개방 비용, 놀이기구 4개, 장식, 줍기 물건)과
앵커 문자열(직전 구역 이름)만 바꾸고, 메시 함수 7개를 새로 쓰면 됩니다.

- `zones_desert_cloud.py`: 사막·구름 구역(스펙 리스트 방식, 처음 만든 형태)
- `zones_sea.py`: 해저 구역(메모리 안에서 모두 바꾼 뒤 한 번에 쓰는 방식)
- `zones_tech.py`: 로봇 도시 구역(`zones_sea.py`에서 생성)

스크립트 맨 앞의 `os.chdir`은 이 저장소의 절대 경로입니다. 적용 뒤에는 `stylua src`,
`verify.ps1`, 메시 생성기 실행, 그리고 Studio에서 OBJ 가져오기와 템플릿 빌더 순서로 진행합니다.
